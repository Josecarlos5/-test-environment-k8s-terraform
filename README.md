# Test Environment with Docker, Kubernetes & Terraform

A maintainable and expandable test environment demonstrating modern DevOps practices using containerization, orchestration, and infrastructure as code.

## Features

- 🐳 Containerized applications using Docker
- ☸️ Container orchestration with Kubernetes  
- 🏗️ Infrastructure provisioning with Terraform
- 🚀 One-command deployment and cleanup
- 📊 Scalable backend API and frontend
- 🗄️ Managed PostgreSQL database

## Prerequisites

- [AWS CLI](https://aws.amazon.com/cli/) installed and configured
- [Docker](https://docker.com) installed
- [Terraform](https://terraform.io) >= 1.0
- [kubectl](https://kubernetes.io/docs/tasks/tools/) installed
- Docker Hub account for image storage
- AWS account with appropriate permissions
